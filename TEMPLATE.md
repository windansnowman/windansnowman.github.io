# Homepage template

Source: https://github.com/jiaxiaojunQAQ/jiaxiaojunQAQ.github.io (main, retrieved 2026-10-09).
Original: https://github.com/RayeRen/acad-homepage.github.io.
MIT license: LICENSE-ACADHOMEPAGE.

The entire upstream Sass theme, assets/css/main.scss, JavaScript bundle, default
page layout, profile structure, and paper-box / ul / li publication structure
are used without custom visual overrides. Personal text, links, portrait,
publication data, and populated sections belong to Zefeng Wu. Publications form one list in reverse chronological order, without author-role
groups or counts. Biography text is preserved with the reference's plain styling.

Root-relative asset URLs retain compatibility with the existing publication
and patent pages. Analytics is not enabled. Legacy content and its inputs are
retained; the upstream source license remains alongside the existing license.
